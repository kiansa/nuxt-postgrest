**Nuxt PostgREST** connects a Nuxt app to a self-hosted [PostgREST](https://postgrest.org) API. It gives you typed query builders in components and server routes, runs every query as the signed-in user so Postgres row-level security (RLS) applies, and provides a server-only admin client for privileged work.

It doesn't sign users in. Use any auth library for that, then mint a PostgREST JWT for the user with `mintJwt()` and store it with `setPostgrestToken()`. The module sends it on every request, in the browser, during SSR and in server routes.

```vue [app/pages/todos.vue]
<script setup lang="ts">
const client = usePostgrest()

const { data: todos } = await useAsyncData('todos', async () => {
  const { data, error } = await client.from('todos').select('id, title').order('id')
  if (error) throw error
  return data
})
</script>
```

## When to use it

Use this module if you run PostgREST yourself (Docker, Kubernetes, a VPS) and want a Nuxt-native way to call it. If you are on Supabase, use [`@nuxtjs/supabase`](https://supabase.nuxtjs.org) instead: it covers Supabase Auth, Storage and Realtime, which this module intentionally does not.

## What you get

| Composable | Where | Acts as |
| --- | --- | --- |
| `usePostgrest()` | Components, pages, plugins (client + SSR) | The current user, or anon |
| `usePostgrestUser(event)` | Server routes | The requesting user, or anon |
| `usePostgrestAdmin()` | Server routes | Your privileged secret role |
| `createPostgrestClient()` | Anywhere | Whatever key you pass |

All four return a standard `PostgrestClient`, so everything in the [postgrest-js API](https://supabase.com/docs/reference/javascript/select) works: filters, embedding, `rpc()`, `.schema()` and more.

Three server utilities connect your auth library to those clients, see [Authentication](/guide/authentication):

| Utility | What it does |
| --- | --- |
| `mintJwt(claims, options?)` | Signs a PostgREST JWT for a user |
| `setPostgrestToken(event, token)` | Stores it in the cookie the composables read |
| `clearPostgrestToken(event)` | Removes the cookie, for example on logout |

And a CLI, `nuxt-postgrest types`, generates your `Database` type, see [Types](/guide/types).
