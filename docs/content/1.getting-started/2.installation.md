### Install the module

```bash [Terminal]
npx nuxi module add nuxt-postgrest
```

### Point it at PostgREST

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-postgrest'],
  postgrest: {
    url: 'http://localhost:3001',
  },
})
```

Or leave `url` out and set it per environment:

```bash [.env]
NUXT_PUBLIC_POSTGREST_URL=https://api.example.com
# Optional: anon JWT used when no user is logged in.
# Leave unset to let PostgREST fall back to its db-anon-role.
NUXT_PUBLIC_POSTGREST_KEY=
# Server-only: JWT for a privileged role, used by usePostgrestAdmin()
NUXT_POSTGREST_SECRET_KEY=
```

### Query

```vue [app.vue]
<script setup lang="ts">
const client = usePostgrest()

const { data } = await useAsyncData('todos', async () => {
  const { data, error } = await client.from('todos').select('*')
  if (error) throw error
  return data
})
</script>
```
::

::note
Requires Nuxt `>=4.0.0`.
::
