### Install the module

```bash [Terminal]
npx nuxi module add nuxt-postgrest
```

### Point it at PostgREST

```bash [.env]
# nuxt-postgrest
NUXT_PUBLIC_POSTGREST_URL=http://localhost:3001
# anon role used when no user is logged in.
NUXT_PUBLIC_POSTGREST_KEY=
# Server-only: Service role, used by usePostgrestAdmin()
NUXT_POSTGREST_SECRET_KEY=
# Server-only: signs user tokens in mintJwt(). Must equal PostgREST's jwt-secret.
NUXT_POSTGREST_JWT_SECRET=
```

The module has no options of its own. Everything is `runtimeConfig`, so you can also declare the keys in `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-postgrest'],
  runtimeConfig: {
    public: { 
      postgrestUrl: '', // automatically read from NUXT_PUBLIC_POSTGREST_URL
      postgrestKey: '' // automatically read from NUXT_PUBLIC_POSTGREST_KEY
      },
    postgrestSecretKey: '', // automatically read from NUXT_POSTGREST_SECRET_KEY
    postgrestJwtSecret: '' // automatically read from NUXT_POSTGREST_JWT_SECRET
  },
})
```

### Query

```vue [app.vue]
<script setup lang="ts">
const client = usePostgrest()

const { data } = await useAsyncData('todos', async () => {
  const { data, error } = await client.from('todos').select('*')
  if (error) throw error
  return data
})
</script>
```
