### Install the module

```bash [Terminal]
npx nuxi module add nuxt-postgrest
```

### Point it at PostgREST

```bash [.env]
NUXT_PUBLIC_POSTGREST_URL=http://localhost:3001
# Optional: anon JWT sent when nobody is signed in. Leave empty to use PostgREST's db-anon-role.
NUXT_PUBLIC_POSTGREST_KEY=
# Server-only: JWT for a privileged role, used by usePostgrestAdmin()
NUXT_POSTGREST_SECRET_KEY=
# Server-only: signs user tokens in mintJwt(). Must equal PostgREST's jwt-secret.
NUXT_POSTGREST_JWT_SECRET=
```

The module has no options of its own. Everything is `runtimeConfig`, so you can also declare the keys in `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['nuxt-postgrest'],
  runtimeConfig: {
    public: {
      postgrestUrl: '', // set by NUXT_PUBLIC_POSTGREST_URL
      postgrestKey: '', // set by NUXT_PUBLIC_POSTGREST_KEY
    },
    postgrestSecretKey: '', // set by NUXT_POSTGREST_SECRET_KEY
    postgrestJwtSecret: '', // set by NUXT_POSTGREST_JWT_SECRET
  },
})
```

### Query

```vue [app/app.vue]
<script setup lang="ts">
const client = usePostgrest()

const { data } = await useAsyncData('todos', async () => {
  const { data, error } = await client.from('todos').select('*')
  if (error) throw error
  return data
})
</script>
```
::

::note
Requires Nuxt `>=4.6.0`.

The module's server utilities use Nuxt's portable `nuxt/server` helpers, so they are written for Nuxt 5 as well. Nuxt 5 isn't released yet and this module hasn't been run against it. When it lands, note that Nuxt 5 stops auto-importing Nitro helpers such as `defineEventHandler` in your own `server/` files: import them from `nuxt/server`. The utilities in this module (`usePostgrestUser()`, `mintJwt()` and the rest) are registered by the module itself.
::
