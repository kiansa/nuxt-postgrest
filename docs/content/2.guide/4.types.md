Clients are typed from a `Database` type in the format produced by `supabase gen types typescript`. The module reads it from `#shared/types/database.types.ts`. Without the file, clients are untyped.

```ts
const client = usePostgrest()

const { data } = await client.from('todos').select('id, title')
//      ^? { id: number, title: string }[] | null

client.from('todo') // ❌ compile error: unknown table
```

## Generating the file

The module ships a CLI that generates the file with the Supabase CLI. It doesn't depend on Supabase hosting, only on a Postgres connection string.

Add the connection string to your `.env`:

```bash [.env]
DATABASE_URL=postgres://postgres:postgres@localhost:5432/postgres?sslmode=disable
```

::note
The Supabase CLI connects over TLS by default. A local Postgres without SSL needs `?sslmode=disable`, as above. Hosted databases usually don't.
::

Add one script to your `package.json`:

```json [package.json]
{
  "scripts": {
    "db:types": "nuxt-postgrest types"
  }
}
```

Run it whenever your schema changes, then commit the file so builds and CI don't need database access:

::code-group

```bash [pnpm]
pnpm run db:types
```

```bash [npm]
npm run db:types
```

::

### What it does

1. Reads `DATABASE_URL` from the environment, or from `.env` and then `.env.local`.
2. Runs `supabase gen types` with `pnpx` if pnpm is installed, otherwise `npx`.
3. Writes the result only if generation succeeded. A failed run never overwrites your existing file.
4. Formats the file with [oxfmt](https://oxc.rs/docs/guide/usage/formatter.html).
5. If your `package.json` has a `lint` script, runs it with `--fix` and the file path appended. For an `eslint .` script that fixes the whole project, so set `--lint` if you'd rather target only the types file.

### Options

| Flag | Default | Description |
| --- | --- | --- |
| `--schema <list>` | `public` | Postgres schemas to include, comma separated. |
| `--path <file>` | `shared/types/database.types.ts` | Where to write the types. |
| `--env-file <file>` | `.env`, then `.env.local` | Env file that holds `DATABASE_URL`. |
| `--lint <command>` | The `lint` script, if there is one | Command that fixes the file, run with the path appended. Pass `false` to skip linting. |

```json [package.json]
{
  "scripts": {
    "db:types": "nuxt-postgrest types --schema public,auth --lint \"eslint --fix\""
  }
}
```

## Non-default schemas

Include the schema in the generated `Database` type with `--schema`, for example `--schema public,internal`. Each schema becomes a key of `Database`, and you target it with `.schema()`:

```ts
const db = usePostgrestAdmin()

await db.schema('internal').from('audit_log').select('*')
```
